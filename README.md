# 词义

手写 / 拼音 / 汉字查字查词工具。

Live: https://qishenmeqi.github.io/ciyi/

## 功能

- 20 格手写（4 排 × 5 列），每格写一个字，写过字的格子可单独清空
- 手写词和成语；某个字识别错误时，结合其他正确的字自动推断
- 拼音查字查词，结果分“同音字词”和“相关字词”
- 查单字时显示可组的词、同音字/词及意思
- 释义按读音分组，多义项才编号，单义项不编号
- 成语例句使用现代汉语，古文出处折叠显示

## 数据来源

- 词语、汉字、成语：mapull/chinese-dictionary、pwxcoo/chinese-xinhua（MIT）
- 词频筛选：fxsjy/jieba（MIT）
- 手写识别：hanzilookup-js / HanziLookup / Make Me a Hanzi
